## Slice 7 — v2.7.0 (screenplay conventions + Final Draft compatibility)
Shipped:
- `.fdx` import rewritten as a real XML tree walk. Cause of the missing scene headings (found by reading the sample scripts embedded in Final Draft 13's exe with `strings`): Final Draft puts nested `<Paragraph>`s inside a Scene Heading (`<SceneProperties><SceneArcBeats>…`, `<ScriptNote>…`), and the old flat scanner took those inner paragraphs as the heading and lost its own `<Text>`. Now only a paragraph's own `<Text>` children are read; also fixed `Style=` matching `AdornmentStyle=`, `AllCaps`, hex entities, CDATA, missing `Type`, Outline/Panel/New Act/Cast List types (nothing is dropped, unknown types become General).
- Author name on the title page is upper case in every template (also in the exported `.fdx`).
- `NAME (CONT'D)` appears automatically when the same character speaks again in the same scene (action, parentheticals or dialogue in between; another speaker or a new scene resets it). It is drawn after the name (`PLine.suffix`), never stored in the text. Not applied inside dual dialogue.
- A dialogue (or action) cut by a page break now ends on the last complete sentence (the rest of that line moves to the next page), `(MORE)` sits under it aligned with the character name, and the next page starts with `NAME (CONT'D)`. Works for blocks longer than two pages. `(MORE)` / `(CONT'D)` are English for every script language (as requested).
- The Scenes panel is closed on launch, new scripts and opened scripts; only the Scenes button opens it.
Verified: 66 vitest (new: FDX with nested SceneProperties/ScriptNote, CONT'D rules, sentence-aware split incl. 3+ page dialogue); tsc strict; `pnpm build`; 31 end-to-end checks (e2e/v26.cjs, updated for the closed panel).
Not verified: real Windows exe; no real Final Draft 13 .fdx file was available, the parser was checked against the structures embedded in its exe.
